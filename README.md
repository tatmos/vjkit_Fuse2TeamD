vjkit_Fuse2TeamD
================
FuZeイベント向けプロジェクト

# タイトル
vjkit_Fuse2TeamD - FuZeイベント向けUnityプロジェクト

# 概要
本リポジトリは、FuZeイベント向けのUnityプロジェクトです。VJ向けの演出やインタラクティブなコンテンツをチームで制作・統合することを目的としており、各メンバーが担当する演出や機能をAssets配下で分担して開発し、最終的に統合して完成度を高めます。

# 構成
- `Assets/`: 各メンバーの成果物やシーン、スクリプト、素材などを配置するルートフォルダ。
  - 例: `Scenes/`（各演出のシーン）、`Scripts/`（C#スクリプト）、`Materials/`（マテリアル）、`Shaders/`（シェーダー）、`Prefabs/`（再利用可能なオブジェクト）、`Textures/`・`Audio/`（素材）。
  - メンバーごとの作業フォルダも `Assets/` 直下に配置し、演出・素材・スクリプトをまとめて管理。
- `ProjectSettings/`: Unityのプロジェクト設定一式。
- `Assembly-CSharp*.csproj`: Unityが生成するC#プロジェクト関連ファイル。
- `README.md`: 運用ルールや作業指針のメモ。

# 使い方
1. Unityで本プロジェクトを開く。
2. `Assets/` 直下に各自の作業用フォルダを作成する。
   - 既存の `tatmos` フォルダをコピーし、リネームして使用するのが推奨。
3. 自分のフォルダ内でシーンや演出、スクリプト等を作成する。
4. 作業内容をコミットし、マージ対象として共有する。

# 主な機能
- VJイベント向けの映像演出やリアルタイム演出の制作・統合。
- 複数メンバーが同時に作業できるAssets配下の分業構成。
- Unityプロジェクトとしての一括管理と、必要に応じたマージ運用。

# Assets以下の詳細
- `Assets/Scenes/`
  - 各演出やデモのシーンを格納。演出単位でシーンを分け、名前に担当者や用途を含めると管理しやすい。
- `Assets/Scripts/`
  - 演出制御や入力処理、タイムライン制御などのC#スクリプトを配置。
- `Assets/Materials/`・`Assets/Shaders/`
  - 表現の質感やエフェクトに関わるマテリアルとシェーダーを管理。
- `Assets/Prefabs/`
  - 再利用したい演出用オブジェクトやUI部品をPrefab化して保存。
- `Assets/Textures/`・`Assets/Audio/`
  - 映像素材や音素材を格納。必要に応じてサブフォルダで分類。
- `Assets/<member-name>/`
  - 各メンバーの作業領域。シーン・スクリプト・素材をまとめて保管し、他メンバーの領域と混在しないようにする。

### 各人はそれぞれ個別のフォルダをAssets/ルートに作成して下さい。
（とりあえず、tatmosフォルダをコピー元として、複製後リネームすると良いです。）

#マージについて

### マージは各人やっても良いし、部分だけ作り込むのでもOKです。
（何か出来たのにtatmosが気がついたら、tatmos側にtatmosがマージします。まだマージしないでとかあればFacebookの方でお知らせ下さい。）
